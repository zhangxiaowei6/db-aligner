# 修改验证与证据记录

## 按需入口

[测试指南](../../../docs/development/testing.md#检查组合)统一维护检查范围、命令与前置条件。文档任务另查[文档检查要求](../../../CONTRIBUTING.md#检查与交付)，不默认读取历史报告。

## 选择与执行

1. 检查本次 diff 并区分已有修改，按影响选择组合，不因文档描述某功能而执行它。
2. 记录实际环境及构建前置；按测试指南使用隔离数据库和资料，避免端口及输出目录冲突。
3. 核对退出码、失败／错误／跳过和覆盖场景，查看相关截图。默认跳过真库不算通过；MySQL 原生客户端只在 8.4.8 分支运行。
4. 文档核对事实、链接、锚点及格式；skills 显式检查 Prettier，逐个使用可用的 `skill-creator/scripts/quick_validate.py`，另查中文元数据和默认提示，不新增业务依赖。
5. 结果写[验证记录](../../../docs/validation/README.md)，视觉结论写[设计 QA](../../../docs/validation/design-qa.md)。注明历史来源、可覆盖报告和未运行项，不手工刷新生成报告冒充本次验收。

技能格式通过不证明客户端发现；预览不证明真库，调试程序不证明完整分发包，打包 smoke 不证明干净安装。仅报告实际完成的验证层级。
