# 支持范围与限制

本工具面向 Windows x64 的结构及基础数据同步。操作步骤见[使用指南](user-guide.md)，实际测试环境及未覆盖项见[验证记录](../validation/README.md)。已实现、风险阻止和未验收分别说明，不以历史结果扩大承诺。

## 数据库与对象支持

MySQL 5.7／8.0／8.4 支持普通 InnoDB 表；PostgreSQL 支持 17.x 普通表。仅在相同数据库类型之间同步。提供工作区、会话导入、指定多表及多目标比较、脚本保存、执行记录、版本归档、外部核验、回滚和本地备份。

### PostgreSQL 能力

支持同类型 PostgreSQL 之间的普通表结构和基础数据同步，按数据库与 schema 选择范围。
MySQL 与 PostgreSQL 之间不进行类型或 SQL 转换。首次使用 PostgreSQL 需要在连接表单安装
目录中的 JDBC 42.7.8；安装后可离线使用。服务器的本次实际验收版本见验证记录，不把浏览器
虚构结果当作真实数据库证明。

- 支持常用内置数值、布尔、文本、二进制、UUID、日期和时间标量；字段定义与注释、表注释、
  普通及唯一 btree 索引、同 schema 外键、基础数据增删改。主键显式建模，变化仍阻止。
- 字段物理顺序和表级字符集不作为可修改能力。恢复删除字段会追加字段，保留原值和定义，
  不承诺原物理位置。
- identity、serial、序列依赖、生成列、自定义类型、数组、CHECK／排他／UNIQUE 约束、分区、
  继承、视图、规则、用户触发器、行级安全、自定义默认函数、表达式／条件／包含列／非 btree
  索引、自定义或非默认索引操作符类、自定义或不确定性排序规则、跨 schema 外键受限。
  唯一性可用普通唯一索引表达。
- 数据模式仍只处理两边存在的同名表，不自动创建 schema 或补入结构。普通表与恢复原值仍遵守
  20,000 行上限、可靠恢复键、连接绑定和未选范围保护。
- 执行账号需要所选 DDL／DML、元数据读取和表锁权限；权限不足停止该目标。新增 schema、序列
  或辅助对象不在执行范围，不关闭约束绕过依赖。
- SSL 验证使用 CA PEM，客户端证书使用 PKCS#12 且别名为 user。不提供自定义 JDBC URL、驱动
  类、任意 JAR、SSH 或动态认证入口。

## 结构同步

支持 MySQL 字段定义、字段顺序、表与字段注释、常规索引、外键、字符集及排序规则。PostgreSQL 细项遵循上述能力边界。高风险和删除变更默认不选，部分结构选择不能创建缺失目标表或自动补入未选依赖。

每次只能比较和同步结构或数据，不能混合（不同表也不能混合）。数据模式只处理源目标都存在的同名表，缺失目标表按目标库自动跳过，不建表、不生成该表的数据变更。字段不兼容时仍要求先同步结构，再重新比较数据；结构模式创建缺失表后需另发起数据同步。

## 数据同步

数据同步面向基础字典等小表，每张表最多 20,000 行，读取超限阻止该表数据同步。不是全量迁移、CDC 或大表增量复制工具。工具不在目标数据库创建备份表、凭据表或快照表。结构变更的字段原值恢复资料在执行前锁内读取并保存在本地记录，同样受 20,000 行上限约束；采集超限时记录跳过，仍可能继续已选结构变更，相关原值需人工恢复。普通读取、序列化或持久化失败则停止该目标，无可靠恢复键的有损字段操作按计划规则阻止，不能将数据超限规则推断为所有结构变更均禁止。

MySQL 数据匹配使用服务器排序规则的权重判断键，空键或重复键阻止同步；源目标匹配键排序规则不一致时要求调整后重新比较。业务键更新保留目标主键。

## 风险与阻止条件

视图、分区、触发器、生成列、CHECK、函数索引 / 不可见索引等复杂对象没有可靠迁移与恢复支持，会阻止同步。不能通过导出的 SQL 自动保证跨版本高级语法兼容；普通表才进入工具执行。

主键结构变更、缺少可靠恢复键的有损字段操作、受外部外键依赖影响的数据删除 / 被引用键更新，采取保守阻止策略。不会自动重映射关联表的外键 ID，也不会关闭外键检查绕过约束。

不支持 SSH 隧道、云 IAM 登录、代理动态认证。PostgreSQL 的支持边界见下文。Navicat 加密密码、DataGrip 外部凭据库不解密；导入 SSL / SSH 等专有参数需人工复核配置。

## 恢复、执行事实与历史删除

回滚要求实际执行证据和匹配的执行后状态，字段原值类恢复还依赖记录内保存的恢复资料（历史记录兼容其目标库备份表）。结构恢复按表组合；数据恢复允许独立行，但后续行修改、外键影响等冲突会禁用对应项。

强制结束程序可能处于“已提交但确认未落盘”的窗口。重启将正在执行记录标为中断并保留证据，核验追加结果；执行范围或恢复证据不明的项不能自动回滚。新表创建后立即中断等情形需人工核实。

外部 SQL 执行受使用工具是否遇错停止、维护窗口和其他并发写入影响。必须登记实际执行范围并通过当前状态核验，才能进入工具回滚；当前状态符合预期不能替代历史证明。

同步记录可编辑备注并显式删除，删除须输入完整记录编号；同时删除专属 SQL、日志和本地恢复资料，不能据此恢复记录或撤销目标数据库变更。排队、执行中及存在父子恢复关联的记录禁止删除，未知状态仍保留原事实。版本删除须输入完整版本号，只解除归属并保留记录。

档案共享、目录身份不符、符号链接或重解析路径会阻止删除；事务失败恢复暂存资料，文件清理未完成时保留可见重试状态。工作区含连接、模板、记录或版本时不能删除，分组含任一工作区连接时不能删除。临时草稿引用允许在删除空资源后清理。

## 权限与本地资料

客户端不创建业务数据库账号或自动授权，也不在目标数据库创建备份、收据或快照等对象。MySQL 执行连接需具备读取、所选 DDL / DML、LOCK TABLES、相关被引用表读取等实际权限；权限不足会按目标记录失败。请使用已有测试库账号验证后再用于其他环境。

密码文件使用 Windows 系统加密，SQLite 普通配置不含明文密码。SQL、行快照、执行日志、归档和本地备份可能含业务数据，保存在用户选择的本机目录。配置导出排除凭据和证书路径，备份不迁移密码。应用不会上传这些资料；更新检查与下载仅访问公开 GitHub Releases，不携带发布 Token。开源提交前应检查忽略规则、全部历史及截图内容。

## 尚未验收与分发边界

Windows 10 / 11 干净机器安装、双向 SSL 客户端证书、各厂商所有历史版本的真实会话导出还未完成验收。当前真库及打包测试范围见验证记录。

Windows Authenticode 代码签名另行配置；Tauri 更新签名是正式更新包的必要条件，两者不可混同。已接入 GitHub Releases 更新检查、确认下载和确认重启安装；自动更新针对 NSIS 安装版，完整便携 ZIP 使用手动覆盖升级。干净 Windows 安装、两个递增正式版本的真实自动更新及远程构建的实际验收范围见验证记录。
