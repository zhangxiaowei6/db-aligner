# Data Sync 交互规范

本规范适用于桌面客户端和浏览器验收预览，按当前确认的交互要求维护。

## 表格与布局

- 所有数据表使用公共 `DataTable`，铺满所在内容容器的可用宽度。表格多余宽度均匀分配给内容列，避免最后一列单独撑开；选择框、计数、操作列保持合理的初始宽度。
- 所有业务列的表头右边缘支持拖拽，也支持聚焦分隔线后用左右方向键调整。列宽最小 64 px；总宽度超过内容区时，在表格内部横向滚动。
- 拖拽感应区位于单元格右边缘内部；不另画分隔线。悬停、拖动或键盘聚焦时高亮表格原有的列分隔线，避免双线和横向溢出。
- 调整某列时优先让其他内容列承担剩余宽度。窗口和侧栏宽度改变后重新计算可用空间。
- 表名和说明分列、单行展示，过长内容省略并提供完整标题；左侧树节点同样禁止换行、禁止双击选中文字。
- 同步范围选表区提供“同步结构 / 同步数据”页签，表格下方只显示当前类型的说明，另用表格上方的全选按钮控制筛选范围的全选和取消。来源／目标数据库共用，结构与数据各自保留选表、搜索条件和编辑内容，切换页签恢复对应草稿；更换来源或工作区重置两种草稿，不同表也不能混合两种类型。表格只显示当前类型的选表与配置列：结构页提供结构细项，数据页提供匹配键，数据模式隐藏结构默认编辑区，刷新反馈按类型分别显示。模板编辑继续遵循已有的类型互斥规则。
- 同步范围的表搜索放在表格正上方，显式标注“搜索表”，提供清空入口，并显示筛选数／总表数与当前类型已选数；搜索只筛选展示，不改变勾选。全选按钮无搜索时显示“全选所有表／取消全选”，有搜索时显示“全选搜索结果／取消选择搜索结果”；部分选中时补齐全选，空列表禁用。表头复选框显示全选和半选状态，与按钮使用同一范围，覆盖当前筛选结果的所有分页。
- 其他同类批量选择也使用一个切换按钮，不并列放置“全选”和“取消全选”。空列表禁用，部分选中时点击补齐全选；全选范围包含分页中的全部行。
- 来源和目标之间的箭头对齐输入框中心，不与字段标签对齐。侧栏右边缘支持拖拽宽度。

## 按钮

| 类型       | 用途                                           | 视觉规则                                             |
| ---------- | ---------------------------------------------- | ---------------------------------------------------- |
| 页面主操作 | 新建工作区、新建连接、新建模板、保存、开始比较 | 蓝色实心按钮；同一操作区避免多个并列主按钮           |
| 普通操作   | 导入、刷新、测试连接、取消、选择文件           | 默认描边按钮，保持现有文本与主题颜色                 |
| 轻量操作   | 全选、取消选择、管理模板、数据库连接、导入连接 | 小尺寸描边按钮，与普通文本明确区分；工具栏保持紧凑   |
| 危险操作   | 删除、批量删除                                 | 红色文字和边框，提交前确认；所有编辑弹窗不放删除操作 |
| 禁用操作   | 必要条件未满足                                 | 使用主题禁用样式；只有操作条件未满足或正在提交时禁用 |

图标和文字之间由按钮组件统一控制间距。图标不单独代替重要操作的文字，连接创建明确写为“新建连接”，不用独立“＋”代替。侧栏沿用项目原有的灰色背景和扁平布局，不额外增加白色卡片或自定义圆角。“数据库连接”作为与“工作空间”一致的区域标题，右侧提供描边“管理”按钮；下面并排放标准尺寸描边的“新建连接”“导入连接”。页面内容区的新建操作仍使用蓝色主按钮。纯文字链接仅用于记录编号等明显的跳转入口；执行操作使用描边按钮。侧栏导航菜单保留菜单样式，工作区齿轮保留原来的图标样式。仅图标工具按钮提供可访问名称。颜色随浅色、深色主题变化，不用硬编码的浅色背景覆盖深色主题。

## 侧栏分区与表结构导出

- 连接树按资源栏的实际可用高度启用虚拟滚动，窗口尺寸变化后更新视口；只挂载可视区域附近的节点，展开／折叠动画同样限制在可视范围。滚动由树内列表统一处理，避免资源栏与树形成双重滚动。保留按需加载、表名省略、右键菜单、键盘导航与拖拽；视口首尾的投放指示线和端点不得被裁剪。
- 折叠分组或连接时同时清除全部下级的展开状态；重新打开上级只显示直接子节点，更深层需要再次手动展开。每次展开连接重新读取数据库列表，每次展开数据库重新读取表清单，之前展开过也不复用旧清单；查询期间清空该分支旧清单并显示加载图标，失败允许折叠后重试，旧请求不得覆盖新的展开请求或其他工作区。每次查看表结构也重新读取结构。
- 数据库节点右键提供“刷新数据表”，更新该库的表清单和当前打开的该库表结构；当前表被删除时关闭其结构详情并返回连接管理。刷新不改变展开状态，不重置同步草稿或已生成计划。加载期间菜单禁用、节点显示转圈；完成后菜单右侧显示勾／叉，悬停或键盘聚焦可查看完整成功信息或失败原因。失败保留上次成功清单，允许再次刷新。表详情中的“刷新表结构”只针对当前表。
- 左侧采用窄功能导航栏加独立数据库资源栏。新建同步、同步模板、同步历史在窄栏上部，设置固定在底部；入口同时显示图标和文字，选中态使用主题浅蓝背景。资源栏只放工作区、连接操作与数据库树，树直接融入灰色背景，不再增加白色卡片或底部“功能导航”标题。
- 数据库资源栏保留宽度拖拽，悬停和拖拽不显示蓝色粗线；保留拖拽光标及键盘调整，键盘聚焦只显示中性细线。
- 选表、全选、切换 DROP 选项及单表入口预选只修改范围，不自动生成 SQL。点击“生成预览 SQL”才请求结构 SQL；未选来源、未选表或加载／提交期间禁用生成按钮。
- 来源、选表或 DROP 选项变化时立即清空预览、禁用导出，并丢弃在途请求的过期结果。修改文件名不影响已生成 SQL；重新生成失败后保持空预览，允许重试。
- 导出页双栏填满可用高度，表列表与 SQL 代码各自滚动；全选、已选数量、复制工具栏及页面底部导出操作保持可达。窄屏改为单栏并允许页面滚动。

## 请求与刷新反馈

- 所有直接发起后端或主进程接口请求的操作按钮，从点击到请求完成显示加载状态，防止重复提交。使用公共 `AsyncButton` 返回并跟踪实际 Promise；处理函数不得用 `void` 丢弃请求。局部请求由对应按钮独立加载，其他无关按钮保持可用；弹窗默认保存按钮显式绑定提交状态。仅修改本地草稿或导航不人为添加加载。
- 刷新、重新加载、失败重试和重新校验使用与测试连接一致的按钮状态：加载时转圈，成功绿色并在文字右侧显示勾，失败红色并显示叉。同一入口的结果保留至再次刷新或对应展示上下文失效（右键重开规则见下文），再次点击立即清除旧结果并进入加载；即使接口瞬间完成也至少保留 300 ms 加载展示，避免点击看起来没有生效；悬停和键盘聚焦显示完整结果及再次刷新提示。不用短暂的消息提示作为刷新完成反馈。
- 刷新菜单保留文字和刷新图标；请求期间加载图标且禁止重复点击，连接树图标同步显示加载，完成后右键项右侧显示勾或叉。错误原因可在悬浮提示查看，数据库和目标表的现有错误区域保留。状态通过屏幕阅读器播报。
- 切换工作区、表、目标范围或修改参数后丢弃过期结果；自动加载与明确点击刷新分开，不把旧数据或其他请求成功标记为本次刷新成功。
- 连接树普通悬停使用点击指针；静止按住同一节点 400 ms 后显示抓取手势；按住后移动即可立即开始原生拖拽，不必等待阈值或手势出现。阈值前移动超过 6 px 只取消长按手势计时，不拦截拖拽；普通单击、松开、取消或投放到无效区域后恢复点击指针。

## 操作状态归属与右键菜单

- 操作反馈归属于实际发起请求的模块、对象、操作入口和展示轮次。公共组件复用样式与行为，调用方显式提供作用域；禁止使用全局忙碌状态驱动无关按钮的加载、禁用、颜色或勾叉。只有同一提交或有明确业务冲突的操作才共享提交保护；同步执行和仅保存互斥，回滚提交防止重复。
- 连接树、同步范围、模板编辑弹窗和结构导出页各自持有数据库刷新反馈。连接树测试、管理列表行、编辑弹窗和导入行的测试反馈互相独立。同一模块也按连接、表、记录、脚本页签及回滚预览区分；更换对象、范围、重开弹窗或离开页面后，过期结果不能覆盖当前反馈。
- 数据库缓存和真实资源加载可以共享，也可以合并相同请求；其他入口更新数据不得让当前刷新按钮显示为正在刷新或已成功。自动加载可在选择器／内容区显示资源加载提示，不作为明确点击刷新按钮的结果。目标表清单按同步类型和实际来源／目标范围区分，工具栏刷新与错误区域重试分别反馈。
- 连接右键的“测试连接”“刷新数据库”和数据库右键的“刷新数据表”使用同一反馈规则：默认菜单文字，加载转圈，成功绿色文字和右侧勾，失败红色文字和右侧叉。加载至少展示 300 ms，禁止对应操作重复提交；完成后可再次点击，重试立即清除旧结果。未操作时不显示悬浮提示，菜单重开清空结果后也不显示“点击再次”等提示。只有正在执行或已有本轮结果时，悬停或键盘聚焦才显示完整结果、可理解的错误原因和再次操作提示，保留礼貌状态播报，不重复弹出全局消息。
- 点击这三项后菜单在请求期间及完成后保持打开；点击外部或按 Esc 关闭。编辑、更换分组、删除、同步和导出等入口关闭菜单后执行原有流程。“刷新数据表”重新读取该数据库的表清单，更新树节点，并按现有规则刷新当前已打开的同库表结构；表详情中的“刷新表结构”仍是单表操作。
- 每次实际右键事件建立新的菜单轮次，清除本轮菜单中测试和刷新的成功／失败提示；菜单已打开时再次右键也重置。旧请求继续执行，未完成时保留加载和防重复保护，结束后恢复可点击，但旧结果不得填入新菜单。关闭菜单、右键其他节点及切换工作区同样隔离迟到结果；重置展示不取消真实请求，也不清空共享缓存。
- 连接右键“编辑连接”直接在当前页面打开统一编辑弹窗，不跳转连接管理。保存成功或取消仍留在原页；取消丢弃草稿，失败保留草稿，沿用校验、系统凭据保护、分组创建和过期响应隔离。其他新建／管理入口保留原有导航规则。

## 连接测试

- 导入行、已保存连接行、编辑弹窗使用同一个测试按钮。按钮文字始终为“测试连接”。
- 初始状态为默认描边。测试中显示加载图标并防止重复提交；其他行可以独立测试。
- 成功后按钮使用绿色文字、边框和淡色背景，文字右侧显示勾图标。失败后使用红色状态，文字右侧显示叉图标。
- 连接管理表格的操作固定为“测试连接 / 编辑 / 删除”，同一行不换行，操作列默认 280px；手动缩窄时仅在单元格内部横向滚动。成功详情不占用可见行高，悬停或键盘聚焦测试按钮时显示完整结果和再次测试提示，并保留状态播报；失败原因在按钮行下方显示。导入表格与编辑弹窗保留可见反馈。
- 成功和失败状态下均可再次点击。再次测试时清除旧结果，测试结束后展示新结果。
- 密码、主机、端口、用户名、SSL、证书、数据库等连接参数改变后清除旧结果。已取消、已修改或已切换工作区的过期响应不能覆盖当前状态。
- 测试不会保存连接或密码。列表测试使用已保存的凭据，编辑弹窗使用当前填写的参数。
- 缺少连接名称、服务器地址、用户名，或端口无效时，测试按钮禁用；弹窗还需选择关联工作区。表单字段失焦和保存时执行必填校验，错误显示在字段下面，不能把缺项标记成“连接失败”。预览接口与桌面接口也校验参数，防止绕过按钮直接请求。

## 编辑表单

工作区、同步模板和设置页不提供“取消修改”或“还原修改”按钮。保留明确的保存操作，弹窗中的“取消”用于关闭弹窗并丢弃当前草稿。

工作区管理、同步模板等列表管理页使用铺满内容区的公共表格，不在右侧常驻编辑表单。页面导航入口只打开列表，不自动选中第一项或弹出编辑表单；仅行内带图标的“编辑”按钮打开编辑弹窗，新建使用同样的弹窗。工作区、模板和连接表格单击或双击行均不打开编辑弹窗。“管理模板”等管理入口也只导航到列表，“将当前范围保存为模板”属于明确的新建操作，可以打开表单。

工作区弹窗约 560px，保留名称、说明，关联连接使用支持搜索的多选下拉框，不使用复选框列表。同步模板弹窗约 960px，保留来源、目标、结构细项、选表和匹配键；长表单内容滚动，底部操作保持可达。保存成功关闭，失败保留草稿；取消、离开页面或切换工作区丢弃草稿，过期保存及表清单响应不得覆盖重开的编辑弹窗。

删除操作统一放在列表操作列，编辑弹窗只放表单和取消／保存，不提供删除按钮。工作区操作为“编辑 / 删除”，模板操作为“编辑 / 应用模板 / 删除”，连接操作为“测试连接 / 编辑 / 删除”；删除提交前保留确认，取消确认不删除。模板应用读取已保存模板并填入范围，用户核对后主动开始比较。模板入口整合在新建同步范围面板顶部，使用支持搜索的模板下拉框，按当前工作区展示全部模板；初始不自动选中或应用。模板下拉标签在上方，选择框与应用、管理模板在同一操作区，同一行控件垂直中心对齐；窄窗口自动换行，选择框保持足够宽度。“将当前范围保存为模板”放在页面底部、开始比较左侧，在当前页打开模板保存弹窗；保存和取消均停留在新建同步页并保留原范围，只有明确点击管理模板才进入管理页。选择只展示名称、说明、来源、目标库数和表数，点击明确的“应用模板”按钮才更新范围。应用中加载并禁止重复操作，成功保留“已应用：模板名称”，可再次应用；修改范围后清除已应用标记，失败显示可重试原因。多个模板不得堆叠为没有用途说明的整块点击卡片。

## 执行同步

点击“执行并保存”或“仅保存记录”后，确认弹窗再次展示来源数据库和实际有已选变更的目标数据库，逐项列出数据库名、连接名、服务器地址和端口，以及每个目标库的变更数量。按目标库展示完整已选同步 SQL，先创建缺失表，再按计划顺序执行其他变更；不包含未选或被阻止的变更。脚本支持滚动查看和复制，确认按钮固定在弹窗底部。无已选变更的目标库说明为本次不执行。执行模式点击“确认执行”后才提交；保存模式明确本次不执行数据库操作，点击“确认保存”后才保存。取消不创建任务或记录。确认期间范围改变时要求重新确认，重复点击不会重复提交。

同步记录详情依次展示“执行脚本 / 回滚脚本 / 执行结果 / 外部执行校验”四个页签。执行脚本直接显示档案中的 `02_sync.sql`；回滚脚本按目标优先显示 `05_rollback_local.sql`，没有时回退到原始 `04_rollback.sql`，按目标数据库和连接名称分组，支持复制完整 SQL。页签内没有文件选择列表、README、备份或校验文件。脚本加载失败时显示具体原因及重试按钮，切换记录时不显示前一记录的脚本。外部执行校验分别展示用户声明范围、当前状态验证和恢复资料可用性；客户端执行记录在执行结果中查看状态。当前状态核验放在执行结果页签内。

工具不在目标数据库创建任何备份表、凭据表或执行后快照表。执行与外部脚本包的回滚能力依赖记录内保存的字段原值、行数据（每表上限 20,000 行）与本地档案；删除字段或改字段定义的自动恢复要求该表有可用恢复资料，否则该项在回滚预览中标记为需人工恢复。仅保存记录的外部脚本包包含 `00_full_diff.sql`、`02_sync.sql`、`04_rollback.sql` 与 README，以及计划、目标和选择资料；新记录登记外部执行只登记实际执行的变更。旧记录仍核验原有备份、收据与执行后快照，不自动清理历史对象。

连接树沿用项目配色与圆角，内部上下留白 16px、左右留白 8px。导入表格中的测试按钮和状态反馈垂直居中，反馈不再带额外上外边距；保持测试结果颜色和再次测试行为。连接行单击选中、再次单击或点击树内空白取消，同一时间至多选中一行；连接可拖入分组并调整组内顺序，分组可拖至同级分组前后排序，不支持嵌套。分组与组内连接的顺序保存到本地配置，重启后保留；同步和模板的来源、目标数据库下拉选项遵循侧栏的分组顺序及组内连接顺序，过滤工作区后仍保留该顺序。拖拽高亮由树组件统一管理，拖拽结束（完成、Esc 取消或落入无效区域）后立即清除。

侧栏没有独立新增分组按钮，连接管理页顶部也没有分组操作。分组右键菜单中“编辑分组”下面紧接“新增分组”，分别配编辑和加号图标；直接打开约 360px 的单名称弹窗，不显示分组列表或切换模式按钮。编辑时聚焦并选中当前名称，新增名称为空，创建同级分组；Enter 保存，Esc 或取消丢弃草稿。连接编辑的分组下拉框内保留名称输入和带加号的新增操作。创建成功后选中新分组并保留其他连接草稿，失败保留输入，迟到响应不能改写重开的弹窗或新的草稿。

分组、连接、数据库和表节点的所有右键操作均显示图标和文字，删除项图标随文字呈危险色。树节点只裁剪名称文本，允许拖拽落点指示线及其端点完整显示；指示线和拖拽结束清理继续由树组件管理。

功能栏“新建同步”返回当前范围草稿，比较期间仍可返回查看和停止；主动从库或表的上下文入口开始新的同步，才重置临时范围。切换到设置等页面不会中止比较。

## 差异预览

- 结构／数据页签按完整比较结果中的差异类型显示，无对应差异的页签隐藏；仅一种类型时自动展示该类型，无差异时不显示页签。搜索过滤不改变页签；被阻止的比较项按所选结构或数据范围归类，历史混合计划保留两种类型。

- 点击库、表、字段或其他变更行时高亮当前查看行，与执行用的复选框分开。支持 Enter 查看详情。
- 点击库展示该库所有表的结构与数据变更，点击表展示该表全部变更，不受左侧结构／数据页签和搜索条件限制。汇总中的变更可点击进入明细。
- 所有属性和值对比统一源库在左、目标库在右。字段详情显示类型、允许空、默认值、额外属性、注释、生成表达式、排序规则、字段位置；差异行突出显示并列出修改属性名称。
- 目标表不存在时，完整结构同步生成创建表；数据同步按目标库自动跳过该表，不自动选结构、不生成建表或数据 SQL，不作为阻止项。确认弹窗明确列出缺失目标，差异预览列出实际跳过的库和表名；其他目标库中的同名表继续比较。部分结构仍不能创建缺失表，历史混合计划和记录保留原有缺表依赖说明。
- 新数据计划的缺表项没有可执行变更，不进入保存或执行 SQL；历史混合计划仍在脚本确认前检查创建表依赖。数据详情明确区分“不存在该行”和 SQL `NULL`，缺少字段值时显示“未提供该字段”。

| 内容                 | 位置                         | 持续时间及样式                                                   |
| -------------------- | ---------------------------- | ---------------------------------------------------------------- |
| 字段说明             | 对应字段下面                 | 常驻，13 px 次级文字，行距约 1.6；与输入框留 6–8 px              |

| 弹窗测试结果         | 底部操作栏左侧，紧邻测试按钮 | 常驻，长错误在左侧换行；保存和取消放右侧，操作栏与表单用细线隔开 |

## 验收预览

浏览器预览使用虚构连接，不验证真实数据库凭据。导入页提供 32 条示例用于验收分页、选择和连接测试；参数校验通过后，密码输入 `preview-fail` 模拟失败，其他密码输入模拟成功。真实连接验证使用桌面客户端。

预览比较与引擎保持相同的范围规则：新比较只能选择结构或数据一种类型，不同表也不能混合。数据模式按目标库跳过缺失表，不生成建表或该表的数据变更；已有表的字段不兼容时提示先同步结构，再重新比较数据。旧混合模板应用前选择本次类型，历史混合计划和记录保留原有变更、阻止说明与恢复证据，不据此允许新的混合比较。

- 预览页只提供查看差异、选择变更、保存记录和执行。顶部保留“上一步”，返回来源、目标和选表页面并保留已选范围；不提供新建同步、导出表结构或保存模板的跨阶段操作。
- 面包屑使用“工作区 / 新建同步 / 差异预览”，范围设置页使用“工作区 / 新建同步”。面包屑只显示层级，不可点击；返回统一使用“上一步”按钮。不显示步骤编号。
