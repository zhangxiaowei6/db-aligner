## 真库覆盖

- TLS CA 与主机名校验；中文和含反引号对象名，单引号、反斜杠字符串及 UTF-8 协议。
- 选择范围和同一份源快照、未选触发器表不读取结构 / 数据、多目标独立状态。
- 默认主键、业务键、复合键、大小写不敏感排序、空键和重复键阻止；更新保留目标主键。
- 仅保存不改变目标表摘要、不创建数据库备份；档案保留原始计划、勾选与脚本。
- 新增、更新、删除，结构有损删除字段后从备份恢复原数据与定义。
- 数据部分回滚、其余项继续恢复；后续行修改造成冲突时其他行仍可恢复，冲突不因前一次恢复而被误放行。
- 比较后目标变化，一目标失败、另一目标成功；备份被篡改阻止恢复。
- 预先占用恢复表导致备份失败，阻止业务写入；没有修改账号授权。
- 默认结构导出无 DROP；明确启用时预览 SQL 含 DROP。
- 实际在 JDBC 执行导出的备份、同步与校验 SQL；外部登记、收据与恢复核验通过后回滚，原始未执行状态不被改写。
- 批次取消后已提交行显示部分执行并可恢复；对子引擎执行中强制终止，重启显示中断、追加状态核验、不把未知执行窗口当作未执行或已撤销。
- 版本追加 / 显式移动、事务失败不部分更新、原始脚本和状态保留；本地备份恢复、ZIP 目录穿越拦截、XML XXE 拦截与三种会话格式解析。
