# 使用指南

## 工作区与连接

工作区对应项目；一个连接可关联多个工作区。连接管理支持分组、数据库范围、用户名、密码和 SSL。数据库范围留空时，展开左侧连接可列出服务器可访问的数据库；填写范围时只展示允许的数据库。连接测试可在保存前检查当前输入。

密码通过 Electron 主进程调用 Windows 系统加密保存。编辑时不回填明文密码，留空保持已存密码；使用清除密码选项可以移除。CA 证书用于验证服务器与主机名，客户端证书配置接受 PKCS#12。证书路径为本机路径。

会话导入先选择工具与文件，或粘贴 XML / JSON，点击解析后勾选连接。重复项可以跳过、更新或作为新连接导入。更新重复项会保留已有工作区关联。Navicat 的加密密码与 DataGrip 外部凭据库不解密，需要补充。SSH 配置不能直接迁移为隧道，请使用直连。

## 左侧表与任务

双击表名或右键“查看表结构”会打开独立结构标签，已有同步草稿保留。字段、索引、外键、表属性和建表 SQL 分页展示。同步与导出在表、数据库右键菜单和顶部操作入口均可访问。表级入口预选当前表，数据库级入口进入选表页。

同步范围先选源库和多个目标库，然后勾选具体表的结构、数据。未选表不读取结构或数据。基础数据默认按主键匹配，也可填写逗号分隔的业务键 / 复合键。业务键更新保留目标主键；新增行可能由目标生成自增主键，不会自动映射其他表的外键 ID。

已有表的字段定义、增删或顺序发生变化时，先同步结构，再重新比较数据。数据页会明确阻止该次同表的数据变化。模板只保存范围规则，使用模板重新读取真实状态。

## 差异与执行

结构差异层级为“目标库 → 表 → 字段 / 索引 / 外键”，数据差异为“目标库 → 表 → 记录”。点击变更查看源、目标与 SQL。风险项默认关闭，阻止项显示具体原因。仅选中的变更进入执行脚本，完整差异保留供审阅。

“仅保存记录”不写目标数据库，状态是未执行。脚本包每个目标库包括备份、同步、校验、回滚及说明；按说明顺序执行，遇到错误停止，并安排维护窗口以避免其他应用同时写入。完整差异文件不可作为全部执行清单。

“执行并保存”先归档，再检查目标是否仍与比较时一致，准备和验证受影响表的备份，然后执行。各目标结果独立保存。数据以事务批次提交，结构操作逐项记录。备份失败、目标漂移和不可靠恢复会阻止对应目标执行。执行中可以停止后续任务，已提交的变更仍保留真实状态。

计划绑定比较时的目标地址、用户、SSL、证书路径和数据库范围。修改这些连接配置后需要重新比较；历史核验与回滚要求恢复原连接配置。修改连接名称、分组或工作区关联不影响绑定，密码不进入计划。

## 历史、版本与外部执行

每次保存、执行和回滚都生成独立记录。历史页勾选多条记录，再标记版本号及说明；可以追加到已有版本。每条记录归属一个版本，移到其他版本需显式勾选移动选项。版本归档不会改变记录执行状态或覆盖原脚本。

外部执行先在记录详情登记执行范围、备份是否实际完成和说明，再校验目标、脚本收据、执行后快照与恢复资料。登记内容、当前状态核验与恢复可信程度分开显示。仅“数据看起来符合预期”不代表所有脚本曾经成功执行。无可信证据的变更不能由工具自动回滚。

异常中断后记录显示中断；“核验当前状态”追加当前目标与恢复资料结果，不改写原始执行证据。

## 回滚

从记录详情进入回滚预览。数据按记录检查后续变化，被修改的记录禁用，其他可恢复行可单独选。结构按表检查，并要求同表相关变更一起恢复，以保护依赖和字段顺序。备份损坏、资料缺失、外键联动风险或执行状态不明会阻止自动恢复。

回滚以逆向 SQL 和实际备份执行，生成关联记录，原记录保持存档。结构 DDL 不依赖普通事务回滚。一次部分回滚后，可继续预览原记录恢复剩余可信变更；已恢复项不会重复执行。回滚记录本身不能再次反向恢复，需要重新比较。

## 导出与资料管理

结构导出选择数据库和表，可预览、复制和保存 SQL。每个新任务的“包含 DROP TABLE”默认关闭，启用后显示会删除已有表及数据的提示，预览与导出内容同步更新。

设置默认四个目标并发、同服务器一个任务、每批五百行，默认长期保留记录与恢复资料。可以选择归档目录、导出无密码连接配置、备份本地 SQLite 与档案或恢复备份。备份不包含系统加密密码，迁移到其他电脑需要补充密码和证书。

清理会列出受影响记录并禁用其工具内回滚。目标数据库中的恢复备份表保留，不自动删除，以免破坏恢复证据；需要时由维护人员在确认不再需要恢复后处理。

## 比较范围、结构细项和停止

选择源库和目标库后，逐表启用结构或数据。结构可分别选择字段定义、字段顺序、表注释、字段注释、普通/唯一索引、外键、表字符集与排序规则；“统一结构默认”用于新加载的表，“应用到当前已选结构表”将该设置批量应用到已选结构表，每行“调整”可覆盖。关闭结构保留该表细项，模板也会保存每表设置。旧模板默认全部结构细项。

点击“开始比较”先核对源库、目标库、表名和细项。数据比较需要勾选性能风险确认；选中源库所有表的数据时会突出警告，即使当前列表经过搜索过滤也会按完整表列表判断。确认弹窗不执行数据库全表计数。每表 20,000 行上限不代表多表比较负载很小，应选择实际需要的数据范围。

运行后页面顶部显示数据库、表、阶段、表处理进度、当前阶段读取行数和耗时。可切换页面，顶部“停止比较”始终可见；源库、目标库、选表和工作区在运行中锁定。点击停止无需再次确认，等待“正在停止”变为“比较已停止”后再重试。停止会取消当前比较查询、释放连接并丢弃本次结果，所有范围设置保留；返回“新建同步”继续使用当前范围。

只选注释时保留目标字段类型、默认值和顺序。部分结构选择遇到缺失目标表时，该表显示阻止原因，不创建完整表、不生成数据写入。索引、外键和字段顺序依赖未选的新增字段时，同样明确阻止；需要调整细项后重新比较。纯注释可与数据一起比较，字段定义或顺序变化仍需要先同步结构再重比数据。
