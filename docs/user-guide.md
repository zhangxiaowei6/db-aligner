# 使用指南

本指南按日常操作顺序说明桌面客户端。支持对象和限制见[支持范围](limitations.md)，内部执行与恢复机制见[架构说明](architecture.md)。浏览器预览使用虚构数据，不验证真实连接或同步。

## 工作区与连接

工作区对应项目，一个连接可关联多个工作区。工作区和连接管理入口先显示列表；点击“新建”或行内“编辑”打开弹窗，单击或双击普通行不打开编辑。工作区表单包含名称、说明和可搜索的关联连接多选框。保存成功关闭，失败保留草稿，取消丢弃修改。删除在列表操作列，确认后才提交。

连接表单配置分组、服务器、端口、用户名、数据库范围和 SSL。数据库范围留空时列出服务器可访问的数据库，填写后只展示允许的范围。列表提供“测试连接 / 编辑 / 删除”；保存前可用当前填写参数测试，测试本身不保存连接或密码。成功后的版本信息可悬停或键盘聚焦查看，失败原因显示在测试区域，修改连接参数后需要重新测试。

密码通过 Windows 系统加密保存，编辑时不回填明文；留空保持已存密码，清除密码选项用于移除。CA 证书验证服务器与主机名，客户端证书接受 PKCS#12，证书路径为本机路径。

会话导入先选择工具与文件，或粘贴 XML／JSON，解析后勾选连接。重复项可跳过、更新或作为新连接导入；更新保留已有工作区关联。Navicat 加密密码与 DataGrip 外部凭据库不解密，需要补充。SSH 配置不能直接迁移为隧道，请使用直连。

分组右键“编辑分组”和“新增分组”打开名称弹窗，新建的是同级分组；Enter 保存，Esc 或取消丢弃输入。编辑连接时也可从分组下拉框新增，成功后选中新分组并保留其他连接草稿。

## 浏览数据库与刷新

连接树按分组展示连接，单击选中，再次单击或点击树内空白取消。连接可拖到分组或调整组内顺序，分组可同级排序；重启后保留。同步和模板的数据库选项遵循该顺序。

折叠上级会清除下级展开状态，重新打开只显示下一层。每次展开连接、数据库和打开表结构都重新查询；加载时显示转圈，失败可重试。双击表或右键“查看表结构”打开独立结构页，展示字段、索引、外键、属性和建表 SQL，不丢弃已有同步草稿。

连接右键“刷新数据库”重新读取数据库列表，数据库右键“刷新数据表”重新读取表清单并更新当前打开的同库表结构；当前表已删除时关闭其结构视图。表详情的“刷新表结构”用于当前表。刷新保持数据库展开状态和同步草稿，失败保留上次成功数据。

右键“测试连接”“刷新数据库”“刷新数据表”在请求期间和完成后均保持菜单打开；成功显示绿色文字和勾，失败显示红色文字和叉，悬停或键盘聚焦查看完整结果、原因及再次操作提示。未操作时没有悬浮提示。点击外部或 Esc 关闭；再次右键会清除菜单旧结果，清空后也不显示“点击再次”等提示。正在执行的请求继续完成并保留转圈和重复点击保护，旧结果不会填回新菜单。连接右键“编辑连接”在当前页面打开表单，保存或取消后留在原页，保存失败保留草稿。

测试与刷新反馈归属于发起操作的入口和对象，无关模块不会因此转圈、禁用或显示成功。请求期间不能重复提交，失败提示可查看具体原因。切换工作区、对象或修改参数后不采用过期结果。

## 配置同步范围与模板

### 来源、目标和选表

从“新建同步”或库／表右键入口开始；表级入口预选当前表，数据库级入口进入选表页。选择一个源库、多个目标库，再用“同步结构 / 同步数据”确定类型，每次只能使用一种，不同表也不能混合。

两种类型共用数据库选择，各自保留选表、搜索和编辑草稿；切换页签恢复对应草稿，更换来源或工作区重置两种草稿。未选表不读取结构或数据。

“搜索表”只筛选显示，不改变已选范围。无搜索时全选所有表，有搜索时全选搜索结果；表头和全选按钮都覆盖筛选结果的全部分页。数据模式只同步源目标都存在的同名表，目标缺表按库自动跳过；确认弹窗和差异页列出跳过范围。需要新建目标表时先同步结构，再重新比较数据。

### 结构细项与匹配键

结构可选择字段定义、字段顺序、表注释、字段注释、普通／唯一索引、外键以及表字符集／排序规则。“统一结构默认”用于新加载的表，“应用到当前已选结构表”批量应用，每行“调整”可覆盖；模板保存每表设置，旧模板缺少细项时默认全部开启。

只选注释保留目标字段类型、默认值和顺序。部分结构不能创建缺失目标表，索引、外键和顺序依赖未选新增字段时会阻止；调整范围后重新比较。

数据默认按主键匹配，可填写逗号分隔的业务键或复合键。业务键更新保留目标主键，新增行可能由目标生成自增主键；不会自动映射其他表外键 ID。字段不兼容时先同步结构，再重新比较数据。

### 应用与管理模板

范围面板顶部按名称搜索当前工作区模板，选择只展示摘要，点击“应用模板”才填入来源、目标、选表和匹配键。应用成功保留模板名称，允许再次应用；核对范围后主动点击“开始比较”，不会自动比较。

“将当前范围保存为模板”在当前页打开保存弹窗，保存或取消均保留范围并停留当前页。“管理模板”只导航到列表，列表提供“编辑 / 应用模板 / 删除”，删除需确认。编辑弹窗包含名称、说明和同步范围，保存成功关闭、失败保留草稿、取消丢弃修改，不在弹窗内删除。

旧混合模板应用前选择本次类型，取消不改变范围；编辑时默认按结构模式载入并提示，可切换数据模式保存，未保存不改写旧模板。历史混合计划和记录继续展示原有变更与恢复证据。

## 比较、差异与执行

### 开始和停止比较

点击“开始比较”先确认来源、目标、表和细项。数据比较需确认性能风险，选中源库全部表时突出警告；判断按完整表列表，不因搜索隐藏部分表而改变，确认弹窗不执行全表计数。每表 20,000 行限制不代表多表查询负载很小，应只选择必要范围。

比较中显示数据库、表、阶段、表处理进度、当前读取行数和耗时。可切换页面，返回“新建同步”查看或停止；运行时锁定工作区和范围。停止无需再次确认，等“正在停止”变成终态后再重试；它取消当前查询、释放连接并丢弃本次结果，保留范围设置。

### 选择变更并确认

对象列表和差异明细各自滚动。表较多时向下滚动列表，点击字段即可在右侧查看明细，无需回到页面顶部；切换对象会将明细滚回顶部，保留列表位置。窄窗口上下排列两区，各自滚动。

差异按目标库、表和变更项组织，点击查看源、目标属性和值及 SQL；查看与执行勾选分开。风险项默认不选，阻止项显示原因。仅有相应差异时显示结构／数据页签，历史混合计划可显示两种。数据详情区分不存在的行、SQL `NULL` 和未提供字段。

“执行并保存”和“仅保存记录”都先弹窗展示实际来源、有已选变更的目标、范围和完整已选 SQL；无变更目标说明不执行。取消不创建记录或任务；确认期间范围改变需要重新确认。

通过脚本目标选择器查看各目标的完整已选 SQL。大脚本按页阅读，每页约 32,768 个字符，语句可能跨页；页码跳转可查看末页。“复制完整 SQL”复制全文，导出与执行范围不受当前显示页影响。差异与回滚长列表只绘制可视行，分组选择仍覆盖完整筛选范围。

### 保存脚本或客户端执行

“仅保存记录”不写目标，记录状态为未执行。导出包按目标提供完整差异、同步、回滚和说明；完整差异文件不是执行清单。外部执行应按说明顺序进行、遇错停止，并安排维护窗口避免并发写入。

“执行并保存”先归档，复验目标状态并执行。需要恢复原值的有损字段操作会在锁内采集，将原值、结构和摘要落到本地记录与档案；普通读取或持久化失败停止该目标，采集超限的结构变更可能继续，但相关原值需人工恢复。工具不在目标库创建备份、收据或快照对象。

各目标独立记录结果，数据按事务批次提交，结构逐项记录且有隐式提交。停止只阻止后续操作，已提交项仍保留实际状态。计划绑定目标地址、用户、SSL、证书路径和数据库范围；配置变化后重新比较，历史核验和回滚需恢复原配置。名称、分组和工作区关联变化不影响绑定，密码不进入计划。

## 历史、外部核验与回滚

每次保存、执行和恢复生成独立记录。历史列表可选择多条记录标记版本，也可追加已有版本；每条记录归属一个版本，移动需要显式选择，不改变原执行状态或脚本。

记录详情分为执行脚本、回滚脚本、执行结果和外部执行校验。外部执行先登记实际完成范围，再校验目标当前状态和恢复资料；声明、状态核验与恢复可信程度分别展示。状态符合预期不证明脚本曾全部执行。中断后核验只追加证据，不改写原执行事实。

从记录详情进入回滚预览，只选择有可信证据的项。数据恢复检查完整行的后续变化，冲突行禁用，其他行可独立恢复；结构恢复按表检查，并要求选齐同表相关项。原值资料缺失、超限或摘要不符会阻止相关自动恢复；无可靠恢复键、外键风险或执行状态不明同样可能阻止。

回滚脚本按目标优先展示 `05_rollback_local.sql`，没有时回退 `04_rollback.sql`。05 包含已选计划的逆向 SQL，不证明全部步骤已完成；部分失败或中断后先核验实际范围，不能直接整份执行。只保存结构脚本而未读取原值时，不能自动找回有损变更内容；本地记录、`recovery.json` 和脚本应一并保留。

执行恢复仍会重新检查，生成关联记录，原执行事实保留。部分恢复后可继续恢复剩余可信项，已恢复项不重复执行；恢复记录不能再次反向恢复，需要重新比较。总记录失败也可能包含已完成步骤，重试前应核对结果；疑似数据丢失先保留原始资料。

## 导出、设置与资料管理

结构导出选择库和表，点击“生成预览 SQL”后才能复制或保存。选择变化不会自动生成；来源、选表或 DROP 选项改变会清空旧预览并禁用导出。“包含 DROP TABLE”每个新任务默认关闭，开启会提示删除已有表及数据。

SQL 内容在预览区内滚动，大脚本显示分页及总页数，切换内容回到第一页。历史记录的执行／回滚脚本按目标选择后加载，可重试失败脚本；优先显示本地恢复脚本 05，旧档案回退到 04。详细性能边界与后续热点见[性能排查](performance.md)。

设置默认四个目标并发、同服务器一个任务、每批五百行，长期保留记录和恢复资料。可指定档案目录、导出无密码配置、备份或恢复本地 SQLite 与档案；备份不迁移系统密码，迁移电脑需补充密码和证书。

浅色、深色和跟随系统主题选择后立即生效并自动保存；有运行或排队任务时关闭窗口需确认。清理恢复档案会禁用对应工具回滚；历史版本创建的辅助对象不自动删除，需要时由维护人员核实处理。完整能力与未验收边界见[支持范围](limitations.md)。
